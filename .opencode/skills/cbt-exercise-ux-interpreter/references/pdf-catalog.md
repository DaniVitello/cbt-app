# Catálogo de los 15 ejercicios (punto de partida)

Clasificación propia, resumida. Confirmar siempre contra la transcripción.
IDs sugeridos en kebab-case.

| Ejercicio | Mecanismo | Patrón sugerido | Notas de UX / deuda probable |
|---|---|---|---|
| core-beliefs | Cuestionar creencias nucleares | Grupo de tarjetas (3) | Cada tarjeta: creencia + 3 razones de por qué no es cierta. Intro con ejemplo plegable. Deuda: bloque agrupado. |
| reverse-the-rabbit-hole | Reestructurar (generar alternativas) | Entradas repetibles | Par negativo/positivo por tarjeta, agregar más. Pedir que el positivo sea "igual de plausible". |
| i-will-survive | Recursos (afrontamiento, apoyos) | Wizard de 3 partes | Recordar una situación difícil: ritmo suave, pausar/saltear. Prompts como pistas plegables. Texto largo. |
| cognitive-restructuring-of-an-event | Reestructurar | Entradas repetibles (mini-wizard) | Evento → pensamiento → reformulación. El ejemplo del PDF va como ayuda plegable. |
| behavioral-experiments | Testear | Proceso en el tiempo | Creencia + % → hipótesis → creencia alternativa + % → diseño → resultado + % final. Se completa en días: estado "en curso" y retomar. Mostrar los 3 % juntos. Deuda: estado intermedio. |
| thought-record | Identificar + cuestionar + reestructurar | Wizard de 6 pasos | Pausa → disparador (quién/cuándo/dónde/por qué) → pensamiento automático → emoción 1-10 → alternativa → re-puntuar. Selección de estilo de pensamiento. Antes/después de la emoción. Deuda: selección múltiple. |
| problem-solving-self-monitoring | Planificar | Wizard corto (4 pasos) | Problema → meta → qué probó → resultado/satisfacción. Reutilizable como registro repetible. |
| downward-arrow | Identificar creencia nuclear | Cadena dinámica | Cada respuesta genera la siguiente pregunta (elegir una de la lista). Mostrar la cadena como escalera. Cuidado emocional al llegar al núcleo: cierre contenedor. Deuda: cadena + elección de pregunta. |
| progressive-muscle-relaxation | Regulación corporal | Reproductor guiado | No es formulario. Contenido de solo lectura, avance por zonas, ritmo propio, opción de temporizador. Deuda: contenido solo lectura. |
| challenging-catastrophic-thinking | Descatastrofizar | Wizard de 6 pasos | Evento + severidad 1-10 → probabilidad → mejor/peor caso → plan de afrontamiento → "qué le dirías a un amigo" → re-evaluación. Antes/después. |
| dysfunctional-thought-record | Identificar + cuestionar + reestructurar | Entradas repetibles (mini-wizard) | El PDF es una tabla de 7 columnas: NO replicarla. Una entrada = situación → pensamiento + creencia % → emoción + intensidad % → distorsión → alternativa → re-puntuar. Vista de historial sí puede ser tabla. Deuda: selección múltiple. |
| disputing-irrational-beliefs | Cuestionar | Selección + elaboración | Elegir una creencia de la lista (o propia) → elegir 4 preguntas desafiantes → responder cada una desde una perspectiva nueva. Deuda: selección con límite. |
| wdep | Planificar | Wizard de 4 secciones (W, D, E, P) | Quiero → hago → evalúo → plan. Preguntas guía como pistas, no como campos obligatorios. |
| decatastrophizing | Descatastrofizar | Wizard de 5 pasos | Catástrofe como predicción concreta + % → probabilidad → peor/mejor caso + voz de amigo → afrontamiento → "qué necesito escuchar" → re-puntuar %. Antes/después. |
| cataloging-inner-rules | Identificar + cuestionar una regla | Wizard con decisión | Infracción → regla → origen → ventajas/desventajas → decisión (conservar/descartar/modificar) → versión nueva. Ramificación: si descarta, saltear la versión nueva. Deuda: ramificación y elección única. |

## Patrones transversales a decidir una sola vez
- Escala 0-100 vs 1-10: ¿unificar en un mismo componente?
- Cómo se muestra el antes/después (mismo componente en todos).
- Ayudas/ejemplos plegables (mismo componente).
- Cierre con resumen (mismo componente).
